When the model streams, complete Input first, then open one authenticated WebSocket
at `{endpoint}/guardrails/output-stream`. Send the Endpoint token in `x-api-key`.
The gateway keeps its normal client-facing SSE interface. The old POST chunk API
is removed; reverse proxies must allow WebSocket upgrades.

<a id="gateway-stream-request" />

## Start and feed the stream

```json
{"type":"start","version":1,"protocol":"litellm","call_id":"call-123","stream_id":"stream-456","messages":[],"request_data":{},"request_headers":{}}
```

Reuse Input's call ID and routing metadata. Runner sends `ready` with the pinned
release, model revision, requested/effective mode and eight input credits. Each
`delta` uses one credit; `ack` returns it when NeMo consumes the frame. Input
sequence starts at zero. Process incoming events concurrently with sending.

```json
{"type":"delta","sequence":0,"text":"Hello "}
{"type":"delta","sequence":1,"text":"world."}
{"type":"end","sequence":2}
```

<a id="gateway-stream-delivery" />

## Deliver checked output

Only server `delta.text` authorizes client delivery. Validate stream identity and
its independent output sequence. An input `ack` never authorizes delivery.
`completed` permits normal completion after validating counts. `blocked` stops
output; `error` reports check/protocol failure. Both require cancelling upstream.
Disconnect or timeout terminates the stream; no reconnect or replay is supported.

NeMo owns overlapping windows: 200 input fragments with 50 fragments of context,
checked before release. Requested `interruptible` also becomes `window_buffered`.
These are fragment counts, not character limits. Earlier text cannot be recalled.
PII, transformations and other complete-response policies use `full_buffered`:
check once after `end`, then release the original or replacement.

<a id="gateway-stream-end" />

Send `end` only after verified normal model completion. Upstream failure or
truncation must close the stream. Limits: 300 seconds, 100,000 delta frames,
100,000 characters per delta and 1,000,000 total characters. Redis shares call
assignments across replicas, not output buffers. See the repository's
`docs/gateway-integration.md` for the complete fields and executable tests.
