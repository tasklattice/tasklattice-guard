Playground 对草稿预览或已发布的 Guardrail Version 执行试用检测。它展示检测结果，不发布版本，也不修改生产路由。

<a id="playground-how-to-use" />
## 试用正常与违规场景

1. 选择 Guardrail，以及草稿预览或已发布版本。
2. 输入正常样例，例如订单状态查询。
3. 查看 Input 结果、模型调用和 Output 结果。
4. 再试一条违规输入，以及需要替换内容的回答。
5. 将命中 Rule、有效输出和执行证据与预期比较。

结果取决于启用的 Rule 和已配置的模型能力。试用不生成发布依据。发布草稿或 Release 导入版本前，仍需运行必选 Test Case。

<a id="playground-boundaries" />
## 区分预览与生产行为

显式 Playground 评估执行真实检测，即使 Guardrail 的线上模式为 Monitor 或 Bypass。试用不能证明应用的实际交付行为。

应用仍须提交真实流量，并执行返回的 Decision。详见 [Endpoint 接入验收](/document/developer/endpoint-setup#endpoint-verification)。
