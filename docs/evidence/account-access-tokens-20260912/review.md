# Account Access Tokens 验证记录

模式：release_gate；页面：Product Console；用户：管理员与普通账户；主要任务：创建并管理适用于系统 API 的个人 Token。

约束：沿用既有视觉系统；创建默认不勾选任何权限；模块范围和读写语义可见；不保留明文；账户角色是权限上限；Token 无法签发其他 Token。

证据：在独立数据库和 localhost:38186 实际运行当前 Controller，使用合成测试账户，无线上数据。浏览器完成创建表单、选中 Routers 只读、创建成功、关闭一次性密钥、列表展示、撤销确认及 Revoked 状态。Security 导航更新 URL，刷新和浏览器返回恢复正确页面。另以 HTTP 完成真实 Cookie 创建、Bearer 调用、403 和撤销后 401 验证。

首轮桌面截图存在浏览器容器宽度与截图宽度不同造成的黑色区域；改用 fullPage 截图核实真实页面内容完整，避免把截图工具裁切误判为产品溢出。390px 窄屏下实测 document/body scrollWidth 为 375px，未超出视口；表单输入和权限选择纵向排列，底部操作栏与内部滚动正常。已恢复默认视口。


最终结果：相关 10 个测试文件合计 306 项测试通过（本地化边界修正后重跑受影响的 4 个文件共 17 项）；前后端生产构建与 TypeScript 检查通过。构建仍提示既有大体积 bundle。浏览器 error 日志为空。

Account 改为持续挂载的父路由后，General → Security → General 的 URL 和选中状态正确，未保存的合成输入保持，键盘焦点留在所选标签上。测试结束将该未保存输入恢复为原值；测试 Token 均已撤销。
